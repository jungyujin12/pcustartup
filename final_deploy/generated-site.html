GitHub Pages로 무료 공개하기

지금 보이는 결과는 PCU 시스템 안에 이미 저장되어 있습니다. 아래 절차는 자신만의 공개 주소로 별도 배포하고 싶을 때만 진행하세요.

1. 파일 준비

  1. 상단의 HTML 다운로드를 누릅니다.
  2. 다운로드된 파일 이름을 index.html로 변경합니다.
  3. 직접 사용할 이미지가 있다면 HTML과 같은 폴더에 넣습니다. 지정된 파일명은 Img_files_banner_01.jpg, Img_files_logo_01.png, Img_files_section_01.jpg 형식입니다.

2. GitHub에 올리기

  1. GitHub 새 저장소 만들기를 열고 저장소 이름을 정합니다.
  2. Public을 선택하고 Create repository를 누릅니다.
  3. uploading an existing file 또는 Add file → Upload files를 누릅니다.
  4. index.html과 사용하는 이미지 파일을 끌어다 놓고 Commit changes를 누릅니다.

3. 무료 주소 활성화

  1. 저장소의 Settings → Pages로 이동합니다.
  2. Build and deployment에서 Source를 Deploy from a branch로 선택합니다.
  3. Branch는 main, 폴더는 /(root)를 선택하고 Save를 누릅니다.
  4. 잠시 후 https://아이디.github.io/저장소이름/ 주소로 공개됩니다.
주의: Firebase 관리자 JSON, 접근코드, API 키, 개인정보가 포함된 원본 PDF는 GitHub에 절대 올리지 마세요. 공개할 HTML과 공개용 이미지만 업로드하세요.

GPT·Gemini·Claude로 더 수정하기

간단 수정은 이 화면에서 문구와 강조색을 고칠 때 사용합니다. 레이아웃·애니메이션·세부 디자인처럼 큰 수정은 HTML을 내려받아 외부 생성형 AI에 첨부하세요.

사용 순서

  1. HTML 다운로드를 누릅니다.
  2. GPT, Gemini 또는 Claude의 새 대화에 HTML 파일을 첨부합니다.
  3. 아래 예문을 복사하고 대괄호 부분을 자신의 요구사항으로 바꿉니다.
  4. 설명 대신 수정된 전체 HTML을 요청합니다.
  5. 받은 파일을 브라우저에서 열어 PC·모바일·문구·링크를 확인합니다.
업로드 금지: Firebase 관리자 JSON, 접근코드, API 키, 주민등록번호, 상세 주소, 전화번호 등 공개하지 않을 자료는 외부 AI에 보내지 마세요. 사용하는 AI 서비스의 데이터 이용 정책도 확인하세요.

창업 웹사이트 수정 예문

서비스 성격과 디자인 개선
첨부한 HTML은 [서비스명]의 창업 소개 웹사이트입니다.
기존 문구에 없는 사실이나 성과를 만들지 말고 다음 요구사항만 반영해주세요.

- 주요 고객: [고객]
- 가장 강조할 가치: [핵심 가치]
- 원하는 분위기: [예: 신뢰감 있는 산업적 디자인]
- 바꾸고 싶은 부분: [구체적으로 작성]
- 반드시 유지할 내용: [내용]

모바일 360px, 태블릿, 데스크톱에서 깨지지 않게 확인하고 접근성과 가독성을 유지해주세요. 외부 빌드 도구 없이 CSS와 JS가 포함된 단일 HTML을 유지하세요. 설명이나 코드 일부가 아니라 수정된 전체 HTML만 반환해주세요.

취업 포트폴리오 수정 예문

직무 중심 포트폴리오 개선
첨부한 HTML은 [희망 직무] 지원용 포트폴리오입니다.
입력된 경험·역할·성과의 사실관계는 유지하고 허위 경력이나 수치를 추가하지 마세요.

- 가장 강조할 프로젝트: [프로젝트명]
- 지원 직무: [직무]
- 보여주고 싶은 강점: [강점]
- 원하는 분위기: [에디토리얼 / 기술 문서형 / 절제된 미니멀 등]
- 변경 요청: [섹션 순서, 색상, 문구, 이미지 배치]

채용 담당자가 역할·과정·결과를 빠르게 구분할 수 있게 정보 계층을 개선하고 모바일 360px에서도 잘리지 않게 해주세요. 단일 HTML을 유지하고 설명 없이 수정된 전체 HTML만 반환해주세요.

모바일·화면 깨짐 수정 예문

오류와 가독성만 보정
첨부한 HTML의 콘텐츠와 전체 디자인 방향은 유지하면서 다음 문제만 수정해주세요.

- 화면 크기: [예: 360px]
- 문제 위치: [섹션 또는 문구]
- 현재 증상: [겹침, 잘림, 너무 큰 글자 등]
- 원하는 결과: [구체적인 결과]

반응형 구간, 줄바꿈, 이미지 비율, 터치 영역, 색상 대비를 점검하고 기존 기능과 링크를 제거하지 마세요. 수정된 단일 HTML 전체만 반환해주세요.
