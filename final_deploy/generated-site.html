GitHub Pages로 무료 공개하기

지금 보이는 결과는 PCU 시스템 안에 이미 저장되어 있습니다. 아래 절차는 자신만의 공개 주소로 별도 배포하고 싶을 때만 진행하세요.

1. 파일 준비

  1. 상단의 HTML 다운로드를 누릅니다.
  2. 다운로드된 파일 이름을 index.html로 변경합니다.
  3. 직접 사용할 이미지가 있다면 HTML과 같은 폴더에 넣습니다. 지정된 파일명은 Img_files_banner_01.jpg, Img_files_logo_01.png, Img_files_section_01.jpg 형식입니다.

2. GitHub에 올리기

  1. GitHub 새 저장소 만들기를 열고 저장소 이름을 정합니다.
  2. Public을 선택하고 Create repository를 누릅니다.
  3. uploading an existing file 또는 Add file → Upload files를 누릅니다.
  4. index.html과 사용하는 이미지 파일을 끌어다 놓고 Commit changes를 누릅니다.

3. 무료 주소 활성화

  1. 저장소의 Settings → Pages로 이동합니다.
  2. Build and deployment에서 Source를 Deploy from a branch로 선택합니다.
  3. Branch는 main, 폴더는 /(root)를 선택하고 Save를 누릅니다.
  4. 잠시 후 https://아이디.github.io/저장소이름/ 주소로 공개됩니다.
