# PCU 웹사이트 디자인 엔진 v2

고정 템플릿 30개를 색만 바꾸는 방식이 아닙니다. 아래 네 축이 각각 30종이며, 호환 가능한 방식으로 선택됩니다.

- 디자인 콘셉트: 30종
- 전체 레이아웃: 30종
- 색상 팔레트: 30종
- 타이포그래피: 30종

제작 화면에서 네 축을 직접 선택하거나 `AI 자동 선택`을 사용할 수 있습니다. 자동 선택 시 페이지 내용, 참고 사이트·이미지 분석 결과, 페이지 주소를 사용하며 동일 동아리의 최근 조합을 최대 8개까지 피합니다.

## 참고 사이트 기능

공개된 http/https URL만 입력할 수 있습니다. 로컬 주소, 사설 IP, 내부 도메인은 서버 요청 위조 방지를 위해 차단합니다. 사이트의 제목, 색상 단서, 섹션·이미지·내비게이션 밀도를 분석하지만 원본 코드·문구·이미지는 복제하지 않습니다. 로그인 또는 접근 차단이 있는 사이트는 참고 이미지를 함께 올리면 됩니다.

## 배포 파일

- `final_deploy/website-builder.html`: 제작 화면과 OPF089 이력 조회 수정
- `final_deploy/firestore.rules`: 웹사이트 작업·콘텐츠 접근 규칙
- `AI 실행기.exe`: 디자인 엔진과 참고 사이트 분석 실행

웹 파일을 GitHub에 반영하고 Firestore 규칙을 게시한 뒤 최신 AI 실행기를 사용해야 모든 기능이 함께 동작합니다.
