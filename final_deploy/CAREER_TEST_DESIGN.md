# PCU 진로·직무 흥미 탐색 설계

## 목적

학생의 진로를 단정하거나 채용 적합성을 평가하지 않고, 선호 활동과 업무 방식을 정리해 취업 포트폴리오 설계에 활용하는 탐색 도구입니다.

## 방법론

- 직업흥미 30문항: Holland RIASEC 6영역별 5문항
- 업무선호 12문항: 협업, 학습, 리더십, 위험감수, 구조화, 집중 방식
- 응답: 1점(전혀 아니다)~5점(매우 그렇다)
- RIASEC 점수: 각 영역 평균을 0~100점으로 변환
- 결과 코드: 상위 3개 영역을 순서대로 표시
- 추천 직무: 상위 3개 흥미영역과 연결된 직무군을 중복 제거해 제안
- 포트폴리오: 상위 2개 영역에 맞는 증빙과 프로젝트 서술 구조 제안

## 권리 및 표현 원칙

Strong Interest Inventory의 원문 문항, 규준, Occupational Scale, 고유 점수 계산을 사용하지 않습니다. Strong의 다층적 해석 관점만 연구 참고했으며 공식 Strong 검사를 표방하지 않습니다. RIASEC 기반 직업흥미 탐색은 O*NET Interest Profiler 공식 자료를 참고했습니다.

## 데이터

응답과 결과는 Firebase에 저장하지 않고 현재 브라우저 세션에서만 사용합니다. 결과는 학생이 보관하거나 상담에 활용할 수 있는 A3 가로형 1페이지 PDF 리포트로 내려받으며, 취업 포트폴리오 제작 화면으로 전달할 때는 sessionStorage를 사용합니다. 리포트에는 RIASEC 거미줄 그래프, 영역별 점수, 업무 방식 선호, 추천 직무와 포트폴리오 전략을 함께 표시합니다. 학생용 과거 결과 재조회 기능은 제공하지 않습니다.

취업 포트폴리오 제작 화면에서는 PCU 결과지와 외부 진로검사 PDF를 선택할 수 있습니다. 원본 PDF는 서버·Firebase·생성 사이트에 업로드하지 않고 브라우저에서 텍스트만 추출합니다. 추출 내용은 AI 설계 참고용으로만 사용하고 공개 HTML에는 원문을 표시하지 않습니다. PCU 결과지는 화면형 PDF 안에 재분석용 텍스트를 첨부하므로 다시 선택해도 읽을 수 있습니다.

HTML 생성 전에는 `검사 결과를 바탕으로 제작`과 `검사와 별개로 제작` 중 하나를 반드시 선택합니다. 검사 기반을 선택하면 PCU 검사 이동 정보 또는 결과지 PDF가 있어야 하며, 별도 제작을 선택하면 검사 결과를 AI에 보내지 않고 학생이 직접 입력한 희망 직무 또는 희망 산업·진로 분야를 최우선 기준으로 사용합니다.

## 제한

이 도구는 정식 심리검사, 상담 진단, 채용 평가를 대신하지 않습니다. 실제 진로 결정에는 전공, 경험, 역량, 가치관, 노동시장 정보와 상담 내용을 함께 고려해야 합니다.
